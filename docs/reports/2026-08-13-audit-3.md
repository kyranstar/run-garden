# Audit round 3 — security, data lifecycle, performance/cost, time & travel

**Date:** 2026-08-13 · **Method:** 4 parallel read-only subagent audits (code + SELECT-only prod queries), each instructed to adversarially self-verify findings and skip anything fixed in the prior 48h. Domains chosen to be disjoint from rounds 1–2 (UX/polling/coaching/plan-page; garden/COROS-writes/scheduling/insights).

**Roll-up:** 0 critical · 5 high · 7 medium · rest low/info. Prod's stored data passed every referential/duplicate/state-machine invariant expressible in SQL; the soft spots are lifecycle *boundaries* (coach intent vs. the COROS reconciler), a dead-by-guard feature (recovery %), and two architectural drags (PWA precache-first, serialized cross-region D1).

2. **Recovery % guard (T1)** — small fix, restores a dead feature the garden already consumes.
3. **PWA network-first + fix the dead offline-cache regex (P1+P4)** — every deploy stops shipping a stale render.
4. **D1 latency (P2)** — smart placement + `Promise.all` the hot paths + dedupe `cloudPresence`; biggest daily-feel win per line changed.
5. **Garden scan bounds + resumable resim + unmatch resim date (P3+D5)** — deadline-bound (~Nov) given the queued backfill.
6. **Mirror-duplicate rule + repair the live 07-29 twin (D3)**.
7. **Security bundle (S1–S4)** — open redirect, diagnostics/export scoping, origin-check fix, delete `x-device-id`.
8. **Hardening sweep** — UTC-today trio (T3), ingest atomicity (D4), `repairDurations` bound (D6), calendar midnight wrap (T5), studio windows (T6), `coach-adhoc` plan row (D8), sync-notes poll fold (P7), timezone travel banner (T2).
